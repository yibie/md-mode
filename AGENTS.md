## Emacs Lisp

Before creating, modifying, or reviewing Emacs Lisp (`*.el`), read and follow
[Elisp Best Practices](https://github.com/LuciusChen/coding-guidelines/blob/main/elisp.md).

Treat those guidelines as mandatory for this project. Explicit user instructions
and more specific instructions in nested `AGENTS.md` files take precedence.
